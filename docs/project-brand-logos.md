# Project technology logo sources

The project gallery uses technology brand marks rather than generic interface icons. Names remain visible alongside the decorative marks.

Publisher-provided assets (stored unchanged under `public/brand-logos`):

- Expo: https://github.com/expo/logos/blob/main/svg/logo-type-a.svg
- Convex: `Logos/SVG/symbol-color.svg` from https://www.convex.dev/resources/logos.zip
- Figma: `Figma Brand Assets/Figma Icon (Full-color)/Figma Icon (Full-color).svg` from the logo download linked at https://www.figma.com/using-the-figma-brand/
- Three.js: https://raw.githubusercontent.com/mrdoob/three.js/dev/icon.png
- Python: the two-snakes SVG linked at https://www.python.org/community/logos/
- Firebase: https://firebase.google.com/static/images/brand-guidelines/logo-logomark.png

Next.js, React / React Native, TypeScript, JavaScript, CSS, Socket.IO, Flutter, Dart, and GitHub reuse the corresponding brand-symbol paths in the portfolio's existing `public/toolkit-icons.svg` sprite. Monochrome marks use the page's light/dark foreground; other symbols use their brand colors.

AI model names remain text labels. No generic brain or code icon is presented as an official model logo.

These marks identify technologies used by the projects; they do not imply sponsorship or endorsement. Trademark rights remain with their respective owners.

## Toolkit

Toolkit uses the same `TechnologyLogo` component and artwork as the project gallery. Existing sprite marks also cover HTML, C++, Vite, Tailwind CSS, Flask, Google Colab, Gemini, OpenRouter, Vercel, and Git. Monochrome marks are dark on Toolkit's light icon cards. REST APIs is a general concept and retains a globe interface icon.

Additional publisher assets:

- Java: https://dev.java/assets/images/java-logo-vector.png (original light wordmark on a dark inset).
- Firestore: `Product_Logomark_Cloud_Firestore_Full_Color.svg` from https://firebase.google.com/static/downloads/brand-guidelines/firebase-brand-assets.zip
- OpenAI API: original Blossom SVG from the header of https://developers.openai.com/ (SVG extracted without changing its geometry).
- Codex: publisher-provided extension icon from https://marketplace.visualstudio.com/items?itemName=openai.chatgpt (linked from the official Codex IDE documentation).
